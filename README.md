# Naod HD Camera v1.5

Professional Android + iOS camera UI based on the supplied reference photo.

v1.5 additions:
- Live exposure (EV) control
- Stabilization status indicator
- Refined Pro camera controls
- 4K / 1080P / 720P / MAX
- HDR, Grid, Timer, Flash
- Tap-to-focus
- Zoom
- Photo / Video / SLO-MO / Portrait / Time-lapse modes
- Front/back camera
- Gallery saving

Run:
flutter pub get
flutter run


## Build fix
The Dart dot-shorthand syntax that caused the GitHub Actions build error has been removed. The Android workflow now builds without the experimental dot-shorthands flag.
